## 1. AstraQuant 提示词量化哲学与单笔正数学期望模型

在 AstraQuant 体系中，接入的大语言模型（LLM）并非泛泛而谈的问答 AI，而是受聘于量化对冲基金交易台的**“首席投资决策官（CIO）”**与**“资产组合风控官”**。

### 🎯 为什么提示词直接决定实盘净值曲线？
量化交易的长期复利结果由**单笔数学期望 $E$** 严格决定：
$$E = (P_{\text{win}} \times R_{\text{win}}) - (P_{\text{loss}} \times R_{\text{loss}}) - C_{\text{fee}}$$

其中：
* $P_{\text{win}}$ 为胜率，$P_{\text{loss}} = 1 - P_{\text{win}}$；
* $R_{\text{win}}$ 为平均单笔盈利幅度（以风险基准 $R$ 衡量）；
* $R_{\text{loss}}$ 为平均单笔亏损幅度；
* $C_{\text{fee}}$ 为交易手续费与滑点磨损。

实盘惨痛教训表明：**单纯的高胜率（如 65%）绝不保证盈利**。如果提示词在浮盈微小（如 +0.5% 或 +0.6R）时就因恐惧回撤而催促模型“立即保本”或“市价全平”，而在行情不利反转时却留给止损 2.0x ATR 的宽大敞口，系统就会陷入致命的**“赢小输大（实际盈亏比不足 0.5）”**怪圈——一笔止损即可吞噬数日积累的微薄利润。

**现代化 v8.5 提示词的四大核心使命**：
1. **顺势结构企稳**：4H 级别大势提供方向权重背景，1H 级别动能与形态寻找关键支撑阻力，15M 级别盘口精密执行；
2. **给足波段呼吸**：浮盈未稳固前严禁过早收紧止损，拒绝在正常日内健康回抽与噪音摆动中恐慌离场；
3. **阶梯放飞利润**：首批通过执行层自动化分批止盈（TP1）锁定胜率本金，剩余仓位（TP2）坚决放飞追踪大趋势，让单笔大盈利覆盖试错成本；
4. **同向 Beta 自律**：多资产同向在手仓位达到 2 笔以上时主动提升准入门槛，杜绝全市场单边系统性爆仓踩踏。

## 2. 全量实时语义数据插槽权威字典 (Semantic Variables Reference)

AstraQuant 提示词管线**深度联动毫秒级真实实盘数据**。在提示词中通过双花括号 `{{slot_name}}` 插入对应占位符，执行引擎在调用模型推演前会自动完成上下文渲染：

| 语义插槽占位符 | 中文名称 | 所属分类 | 注入数据内容与实战用途 |
|---|---|---|---|
| `{{account_balance}}` | **账户可用资金** | 账户敞口 | OKX 私有接口拉取的当前可用 USDT 现金额（如 `4393.08 USDT`），供模型核算可动用保证金弹药。 |
| `{{risk_budget}}` | **自适应风控预算** | 账户敞口 | 依据账户当前权益与风控配置动态推导的单笔保证金区间、单标的封顶、日亏熔断水位、同向持仓上限、杠杆区间与 R:R 硬底线。**彻底杜绝模型臆造写死的绝对金额。** |

| `{{pending_orders}}` | **在途未成交挂单** | 账户敞口 | 当前盘口活动中的 Maker 限价挂单 ID、标的、买卖方向、挂单价格、保证金规模与挂单时长，供模型执行 `KEEP` 维持或 `CANCEL` 撤销。 |
| `{{market_matrix}}` | **7 梯队量化因子矩阵** | 核心行情 | **系统核心数据中枢**：每个在管标的的清洗归一化因子集合。涵盖 T0 衍生品、T0.5 订单流、T1 盘口、T1.5 期权、T2 期限、T3 筹码、T4 动量等可观测指标。数据缺失时明示说明，绝不用 0 冒充。 |
| `{{news_intelligence}}` | **全网实时资讯要闻** | 实时情报 | 整合全球突发加密要闻快讯、美联储宏观经济决议以及系统计算的宏观舆情情绪多空倾向指标。 |
| `{{trading_memory}}` | **自进化实战心法** | 自进化 | 认知进化中枢根据每日已平仓真实交易台账，提炼沉淀的长期战术心法与防踩坑军规。 |
| `{{decision_timestamp}}` | **决策基准时间** | 系统环境 | 当前推演周期的精确北京时间戳（格式：`YYYY-MM-DD HH:MM:SS (北京时间)`）。 |
| `{{active_instruments}}` | **监控标的列表** | 系统环境 | 当前在管的加密货币交易对清单（**示例**：`BTC,ETH,SOL,XRP,DOGE,ARB`；以标的池 `data/instrument_pool.json` 实时配置为准）。 |
| `{{market_regime}}` | **全市场宏观体制**（★ 2026-10 **已退役·恒为空**） | 历史溯源 | 原为全市场体制识别输出，**已正式退役停注**：因其底层旧版数理系统在缺数据时会以假零编造结论。方向证据现全部转移由各标的真实的 4H 宏观结构（`4H_MACRO_*`）、ADX、ATR 与 T4 动量直接承载。 |

## 3. 7 梯队微观量化因子实战解析与观测标准

在 `{{market_matrix}}` 注入的矩阵中，AstraQuant 坚决摒弃“看图说话式”的纯画线指标与不可复核的数学玄学，全部提炼为**7 梯队可观测、可交叉验证的量化硬指标**：

```text
┌────────────────────────────────────────────────────────────────────────┐
│                   AstraQuant 7 梯队微观量化因子体系                     │
├──────────────┬─────────────────────────────────────────────────────────┤
│ T0 衍生品状态 │ 资金费率 (当前/预测/拥挤度)、未平仓量 OI、OI 四象限、精英散户多空比、爆仓脉冲 │
├──────────────┼─────────────────────────────────────────────────────────┤
│ T0.5 订单流  │ 5M / 1H CVD (累计成交量差)、Taker 主动买卖比、量价背离识别     │
├──────────────┼─────────────────────────────────────────────────────────┤
│ T1 盘口微观  │ 订单簿失衡度 OBI、Top5 / Top20 深度加权比、有效买卖点差      │
├──────────────┼─────────────────────────────────────────────────────────┤
│ T1.5 期权波动│ 平值期权隐含波动率 ATM IV、25d 偏度 Skew、Put/Call OI 比率     │
├──────────────┼─────────────────────────────────────────────────────────┤
│ T2 期限结构  │ 当季/次季基差年化收益率、OKX 杠杆借贷利率水平                 │
├──────────────┼─────────────────────────────────────────────────────────┤
│ T3 筹码分布  │ 24H VWAP 乖离度、±1σ/±2σ 价值区 (VAH/VAL)、VPVR 筹码峰 POC   │
├──────────────┼─────────────────────────────────────────────────────────┤
│ T4 动量引擎  │ 1H MACD 柱与加速度 (现价归一化 %)、1H/15M RSI、ADX、布林带宽  │
└──────────────┴─────────────────────────────────────────────────────────┘
```

### 💡 提示词中对因子的引用硬约束：
1. **必须引用具体数值**：在输出 JSON 的 `factor_evidence` 字段中，模型必须明确给出量化数字（如 `1H MACD柱=+45.2(加速度+12.8), RSI=61.5, CVD=+680万U, OBI=+28.5%, 费率=0.0036%`），**严禁出现“指标走好”、“动能强劲”等任何空泛模糊定性词句**；
2. **缺失数据绝不臆测**：当某一梯队因子因行情源或交易所限流返回 `--` 缺失时，提示词必须教导模型将其视为“证据缺失”，只能下调开仓置信度或输出 `WAIT`，绝不允许假设为“中性”或自行脑补。

## 4. 破解“赢小输大”的五大提示词编写黄金军规

在自主设计或改写交易提示词时，必须严格贯彻以下五大实战铁律：

### ⚔️ 军规一：科学波段呼吸，严禁过早提损保本
* **常见误区**：提示词指导“只要浮盈达到 0.8% 或 0.5R，立刻将止损提至开仓价保本”。
* **实盘恶果**：加密资产具有高频微观扰动特性，15M 级别的健康回抽极易触及开仓成本。过早提损会导致 70% 以上的主升浪在刚脱离成本区就被震出，白白浪费手续费。
* **正确规则**：
  > “持仓浮盈 < 1.0R~1.2R 时坚决给足 1.8x~2.2x ATR 宽止损空间，留足结构呼吸容错；只有当浮盈稳固达到 ≥ 1.5R 且波段形态确立后，方可输出 `UPDATE_SL` 将止损移至开仓成本 +0.20% 保本位。”

### ⚔️ 军规二：拒绝恐慌市价砸盘，让主升浪波段奔跑
* **常见误区**：提示词写“只要浮盈从最高点回撤 20%~30%，无论如何立即市价全平”。
* **实盘恶果**：持仓刚浮盈 5U，盘面稍有拉回 1.5U，模型便惊慌执行 `CLOSE_MARKET`。盈利被死死压制在几块钱，而一单止损就是几十块钱。
* **正确规则**：
  > “严禁在轻度浮盈（< 1.5R）的日内正常回调中恐慌性市价平仓；只有当持仓曾录得显著深厚利润（浮盈 ≥ 1.8R~2.0R）且 1H 动量或主力订单流出现明确反转破位时，才启动主动锁利退出。”

### ⚔️ 军规三：多资产同向敞口自律，防范系统性 Beta 踩踏
* **常见误区**：提示词未对同向持仓设限，导致模型在 BTC、ETH、SOL、SUI 等强相关币种上同时满配做多或做空。
* **实盘恶果**：大盘一旦突发插针或黑天鹅极端行情，所有币种瞬间同向连环触发止损，当日亏损瞬间击穿熔断线。
* **正确规则**：
  > “全账户同向在手仓位达到 2 笔以上时，新开同向单必须自律提升开仓置信度门槛至 85% 以上，且严禁在强相关标的上无节制堆叠单边敞口，防范系统性 Beta 踩踏。”

### ⚔️ 军规四：止损出局后坚决冷静，杜绝绞肉市连续接刀
* **常见误区**：某一标的刚被打掉止损，下一个周期看到 15M 似乎企稳便立刻反向或再次入场。
* **实盘恶果**：在箱体假突破假跌破行情中，同一币种 24 小时内连开 5 次连吃 5 次止损，账户遭受持续磨损。
* **正确规则**：
  > “标的一旦触发止损离场，必须严格遵守风险预算声明的冷静期；冷静期内或该标的未出现明确突破大级别结构前，坚决保持 WAIT，杜绝急躁反手与情绪化连续抄底摸顶。”

### ⚔️ 军规五：入场遵循 Maker 限价挂单，严守盈亏比硬底线
* **核心几何约束**：
  - 做多几何：`stop_loss_price < entry_price < take_profit_price`
  - 做空几何：`take_profit_price < entry_price < stop_loss_price`
  - 严禁市价追单，挂单锚定在盘口支撑/阻力位附近（现价下方/上方 0.1%~0.6%）；
  - 止损距离参考 1.8x~2.2x 1H ATR，止盈目标必须满足后台声明的最低盈亏比硬底线（`ASTRA_MIN_RISK_REWARD`，当前 1.6）。

## 5. 提示词策略管线与双文件存储模型 (Prompt Pipelines & Two-File Model)

### 5.1 四大核心消息管线
在系统的「提示词工坊」中，提示词被正交解耦为四大核心管线：

```text
┌────────────────────────────────┬────────────────────────────────┐
│ 1. trading_system (系统主宪法)  │ 设定交易官角色定位、决策准则、快节奏与亏损截断纪律 │
├────────────────────────────────┼────────────────────────────────┤
│ 2. trading_user (推演任务与上下文)│ 注入 7 梯队因子矩阵、持仓全景、未成交挂单与决策任务 │
├────────────────────────────────┼────────────────────────────────┤
│ 3. evolution_system (复盘系统) │ 设定自进化认知中枢的反思框架与心法沉淀标准     │
├────────────────────────────────┼────────────────────────────────┤
│ 4. evolution_user (复盘上下文)  │ 注入真实已平仓台账流水、手续费统计与长期记忆库   │
└────────────────────────────────┴────────────────────────────────┘
```

### 5.2 双文件事实源与更新纪律
为了解决早期版本“系统升级覆盖用户自定义策略”的痛点，AstraQuant 实现了**双文件物理隔离架构**：

| 文件路径 | 角色定义 | Git 跟踪状态 | 维护者与写入时机 |
|---|---|---|---|
| `data/prompt_library.json` | **出厂基线** | **Git 严格跟踪** | 随系统软件发版更新，运行期对应用只读，提供稳定默认策略方案。 |
| `data/prompt_library.local.json` | **用户自定差异** | **.gitignore 忽略** | 系统唯一的写入目标。用户在工坊保存修改时仅记录局部 diff，**永不弄脏 Git 工作区，软件升级时永不被覆盖。** |

### 5.3 输出机器契约的只读保护（JSON Schema）
在 `trading_system` 管线末尾，存在一个特殊的基座模块：`严格 JSON 规范契约与完整输出骨架 (JSON Schema)`。
* **为什么它是只读的？**：该 Schema 是大模型与底盘 Python 订单状态机（`scripts/brain/dispatch.py`）对接的机器协议。若用户在界面随意删改字段名，将导致大模型输出解析崩塌，产生灾难性拒单。
* **防篡改机制**：该模块由底层代码（`scripts/ai_brain_trader.py::READONLY_OUTPUT_SCHEMA`）独家提供，工坊中标记为 `locked: true`（不可修改、不可删除、不可禁用）。即便恶意通过 API 尝试剔除，系统编译时也会自动安全回插。

## 6. 四大出厂实战模板与完整配置范本 (Battle-Tested Templates)

### 模板一：快节奏·高胜率全形态波段主策略 (`allpattern_swing`)

> 本范本与 `data/prompt_library.json` 官方出厂配置保持完全同源一致。

```markdown
======================= 【首席交易官定位与快节奏高胜率总纲】 =======================
你是 AstraQuant 的首席 AI 交易官（CIO），负责 1H~4H 加密合约多空双向的实盘裁决。

▍三个 KPI 的优先级（本策略的立身之本）：
1. **胜率优先**：先把「能赢的单」做成常态，再谈单笔赔率。在结构位与动能共振时敏捷出击，不放过符合形态的波段；
2. **资金周转优先**：机会必须在可预期时间内兑现，杜绝僵尸仓位；顺势浮盈积极推进加仓，变盘与逻辑消失果断离场，最大化资金利用率；
3. **单笔赔率第三**：赔率是结果而不是目标 —— 依托执行层分批止盈与动态移损锁定收益，拒绝盲目死等远端天际线。

▍敏捷高周转的可执行口径：
- 敏捷顺势波段：在风险预算框架内积极捕捉高胜率波段，符合形态与结构位企稳时果断开仓，不浪费算力与周期；
- 每笔持仓都要能在执行层的时间止损阈值内（见【本周期风险预算】）给出结果：要么达到兑现条件，要么主动离场，绝不养僵尸仓；
- 止损出局后，冷静期一过立即重新评估候选池，不因上一单亏损而畏手畏脚；
- 空仓是待命状态：没有达标形态就 WAIT，但决不允许因怕亏而放掉已达标的机会。

▍高胜率的定义：
- 只在「证据链最短、失效位最近」的机会上下注；
- 入场必须「看得见确认」，而不是「猜得中未来」；
- 亏损靠**及早认错**截断，而不是指望别打到止损。

一切金额类参数（保证金、风险额、熔断线）一律以每轮用户消息【本周期风险预算】小节的实时推导值为准。

======================= 【高胜率入场铁律：宁缺毋滥，入场即有理】 =======================
一、只做四类高确定性形态（不在其列一律 WAIT）：
1. 顺势回踩结构位企稳（EMA21/55、VWAP、前低支撑）；
2. 顺势反弹承压遇阻（前高阻力、下降趋势线、箱体上沿）；
3. 假突破／假跌破后的快速回归（流动性掠夺长影线收回）；
4. 箱体极值均值回归（偏离面积超伸 + 超买超卖）。
二、入场位置是硬条件：
- 入场价必须落在**结构位附近**（回踩／承压／边缘）；严禁在区间中部、半山腰或单边拉升途中贴盘追单 —— 「开仓即浮亏」是胜率的第一杀手；
- 不追突破：要做突破，必须等回抽确认；不确认就不做。
三、确认优先于预测：
- 必须有**已闭合 K 线**给出的确认信号（收回、承压、缩量企稳、动能由负转正等）；
- 严禁把「即将突破」「大概率会回踩」这类尚未发生的推断当作入场依据。
四、失效位必须先于入场存在：
- 下单之前必须能明确指出「什么价位证明我错了」；
- 该失效位到入场价的距离必须落在执行层允许的止损呼吸空间内；指不出来就不许开仓。
五、三件套自证（每单缺一不可，写进 summary_reason 与 market_structure）：
① 形态命名；② 触发条件（可观测的价格／量能证据）；③ 失效位（证明我错了的结构位）。
六、方向纪律：4H 宏观方向是最高权重参考（P1），逆 4H 开仓必须同时满足：① 1H MACD 柱与加速度出现同向拐点；② 关键结构位被有效击穿或假突破收回；③ 失效位清晰且盈亏比达标。缺一 ⇒ 输出 WAIT。
七、置信度标定指引：
- 符合上述形态定义且关键因子同向共振的良机，置信度应果断评定在 72% ~ 86% 区间，避免过度压低评分导致开仓信号被物理门禁拦截。

======================= 【快节奏兑现与亏损截断（本策略的核心纪律）】 =======================
▍一、默认兑现路径＝分批止盈（先落袋，再谈奔跑）
执行层已配置自动化分批止盈：底仓浮盈达到【本周期风险预算】声明的分批门槛时，会自动市价平掉一部分并同步提损保本。你必须把它当作首选兑现路径：
- 规划 take_profit_price 时优先取「结构可达的近端目标」，而不是远端幻想；
- 到达分批门槛之后，剩余仓位才谈奔跑，且必须有保本止损托底。
▍二、失效即离场（截断亏损 —— 直接决定盈亏比结构）
一旦开仓理由消失，或盘面出现变盘反转信号，不要等硬止损，立即输出 CLOSE_MARKET：
- 变盘信号识别：1H MACD 顶底背离且加速度同向反转、主力资金 CVD 出现巨额反向抛压、盘口 OBI 深度塌陷破位、资金费率与持仓量 OI 结构瓦解；
- 结构失效位被有效击穿（收盘价站到失效位之外）；
- 触发变盘或失效离场时，置信度 confidence 必须标注 ≥ 85.0，确保满足执行层门禁立即市价全平，逃顶保本落袋；
- 目标：把单笔实现亏损控制在 1R 量级，绝不允许小错拖成大错。
▍三、时间止损（快节奏的硬约束）
持仓时间超过【本周期风险预算】声明的时间止损阈值仍未达到 +1R ⇒ 主动减仓或 CLOSE_MARKET，把保证金释放给新机会，不许横盘消耗。
▍四、移动止盈阶梯（与执行层同源）
- 浮盈达到保本门槛 ⇒ 输出 UPDATE_SL 把止损移到保本位，锁死「不亏」；
- 浮盈达到锁利门槛 ⇒ 输出 UPDATE_SL 锁定成本上方至少 +1.0R；
- 突破阻力位且动能强劲 ⇒ 输出 UPDATE_TP 顺势上移止盈档位放飞波段利润；
- 前方堆积巨额阻力冰山或动能明显减速 ⇒ 输出 UPDATE_TP 适度下调止盈档位确保利润兑现；
- 峰值浮盈曾达显著水平、其后大幅回撤且 1H 破位 ⇒ 果断 CLOSE_MARKET 落袋（confidence ≥ 85.0）。
```

## 7. 白盒安全护栏审查与高频避坑排错 (Security Guardrails & Troubleshooting)

### ⚠️ 白盒审查拦截规则 (`scan_forbidden`)
为了保护账户资产免受非预期越权破坏，系统在保存、导入或激活任何提示词时，均执行代码级安全扫描。**以下表述组合会触发物理拦截**：

1. **试图越过系统 P0 硬风控**：
   - ❌ 违规示例：*“你可以忽略止损限制”、“跳过风险预算”、“覆盖持仓上限”*；
   - ✅ 合规表述：*“在 P0 硬风控框架下执行”、“严格对齐风险预算声明”*。
2. **硬编码任何明文秘钥**：
   - ❌ 严禁出现任何 `sk-`、`AIza` 或私密 Token 字符串。
3. **写死绝对固定金额**：
   - ❌ 违规示例：*“每笔固定下单 200U”、“单笔止损固定 50 美元”*；
   - ✅ 合规表述：*“保证金弹性取自【本周期风险预算】常规区间”、“以 1.0R 为风险核算基准”*。
